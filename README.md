# Learning Riffs Anki Script

Берёт файл партитуры (.gp3 / .gp4 / .gp5 / .gpx / .gp / .gp7 / .musicxml)
и создаёт PNG-карточки по одному такту, сразу в формате cloze для Anki.

## Что делает

- Каждый такт рендерится **индивидуально** → темп и метр видны на каждой карточке.
- Правая тактовая черта **автоматически обрезается** — при склейке соседних тактов
  они образуют единую нотную картину без двойных черт.
- Файлы называются по заголовку произведения: `MySong_001.png`, `MySong_002.png` …
- Опционально режет MP3-файл (экспортированный из Guitar Pro) на фрагменты
  по тактам и вставляет `[sound:…]` прямо в cloze-текст.

## Установка

```bash
npm install
```

Нативный рендер-движок (alphaSkia) ставится автоматически под твою ОС.
Для нарезки MP3 нужен **ffmpeg** (на macOS: `brew install ffmpeg`,
на Ubuntu: `apt install ffmpeg`).

## Использование

```bash
node split_measures.mjs <файл> [outDir] [trackIndex(es)] [scale] [mp3]
```

| Аргумент        | По умолчанию | Описание |
|----------------|-----------|---------|
| `файл`         | —         | Путь к .gp5 / .gpx / .gp7 / .musicxml или .tex (обязателен) |
| `outDir`       | `out`     | Куда сложить картинки и MP3 |
| `trackIndex(es)`| `0`      | Одна дорожка (`0`) или две через запятую (`0,1`) — см. ниже |
| `scale`        | `1.5`     | Масштаб рендера (1.5–2 = чётче на телефоне) |
| `mp3`          | —         | Путь к MP3 для нарезки по тактам (опционально) |

### Рендер двух дорожек в одной карточке (опционально)

Можно вырезать такт сразу для **двух дорожек** — например, сверху гитарный рифф,
снизу вокальную партию — так, чтобы на одной PNG-карточке был один и тот же такт
для обеих дорожек друг под другом.

Для этого передай индексы дорожек через запятую: **первый индекс = верхняя дорожка,
второй = нижняя**.

```bash
# Дорожка 0 сверху (гитара), дорожка 1 снизу (вокал)
node split_measures.mjs song.gp5 out 0,1

# Порядок можно поменять местами
node split_measures.mjs song.gp5 out 1,0
```

Скрипт при запуске всегда печатает список дорожек в файле с их номерами:

```
🎸 Дорожки в файле:
   [0] Guitar
   [1] Vocal
```

По умолчанию (без запятой) рендерится только одна дорожка.

**Если нижняя дорожка обрезается и не влезает в карточку** — увеличь константу
`BOT_PAD` в `split_measures.mjs` (раздел «7. Нарезка тактов», по умолчанию `14`).
Если, наоборот, обрезается что-то сверху (например, темп/заголовок) — увеличь
`TOP_PAD` (там же, по умолчанию `Math.round(30 * scale)`). Высота кропа
подстраивается под обе дорожки автоматически — трогать нужно именно эти
две константы, если места не хватает.

### Примеры

Только PNG:
```bash
node split_measures.mjs "Cliffs of Dover.gp5"
```

PNG + нарезка MP3:
```bash
node split_measures.mjs "Cliffs of Dover.gp5" out 0 1.5 "Cliffs of Dover.mp3"
node split_measures.mjs "Jimi.gp" out 0 1.5 "Jimi.mp3"
```

## Что получится в `outDir/`

| Файл | Описание |
|------|---------|
| `MySong_001.png` … | PNG-картинки тактов (темп + метр на каждой) |
| `MySong_001.mp3` … | MP3-фрагменты тактов (если передан mp3-аргумент) |
| `_full.png` | Полный рендер партитуры (для справки) |
| `_cloze.txt` | Готовый cloze-текст для вставки в Anki |

### Формат `_cloze.txt`

Без MP3:
```
{{c1::<img src="MySong_001.png">}} {{c2::<img src="MySong_002.png">}} …
```

С MP3:
```
{{c1::<img src="MySong_001.png">[sound:MySong_001.mp3]}} {{c2::<img src="MySong_002.png">[sound:MySong_002.mp3]}} …
```

Этот текст вставляется в то же поле карточки, что и размеченные стихи —
существующий сплиттер раскидает `{{c1::}}`, `{{c2::}}` … по карточкам без изменений.

## Важно про MP3-синхронизацию

Длительность каждого такта рассчитывается из темпа и тактового размера партитуры.
Для точной синхронизации MP3 должен быть экспортирован **без вступления/паузы в начале**
(ровно с первого удара первого такта). Экспорт из Guitar Pro: File → Export → Audio.

Если в произведении меняются темп или тактовый размер — скрипт учитывает это автоматически.

## Как создать карточки Anki

1. Скопировать все файлы (за исключением "_full.png" и "_close.txt") в "..User\AppData\Roaming\Anki2\User 1\collection.media"
2. Убедиться, что у вас есть close-карточка "Generation close card.txt" c 3 полями — Text; Back Extra; Overlapping
3. Открыть окно создание карточки, выбрать close-карточку
4. Нажать "ctrl + shift + x"
5. Вставить в front карточки текст из "_close.txt" как код
6. Ввести в "Overlaping" значение "1, 0, false"
7. Нажать создать карточку

На выходе скрипт автоматически создаст на каждый так по карточке
